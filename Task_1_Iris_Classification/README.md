# Task 1: Iris Classification

## Project Overview
This project compares Logistic Regression and Decision Tree classification algorithms using the Iris dataset.

## Machine Learning Algorithms
- Logistic Regression
- Decision Tree Classifier

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-score

## Objective
To understand and compare the performance of different classification algorithms.
